# Shahd Soliman - Software Developer Portfolio

The official portfolio website of Shahd Soliman, Software Developer and Backend .NET Specialist. This repository contains the source code for the single-page application highlighting engineering projects, architectural patterns, technical competencies, and professional credentials.

**Live Website:** [https://shahdsolliman.github.io/portfolio-/](https://shahdsolliman.github.io/portfolio-/)

---

## Overview

A lightweight, responsive, and self-contained web portfolio built with clean standard web technologies, requiring no third-party UI frameworks or build pipelines. The site emphasizes performance, accessibility, responsive layout, and semantic structure.

## Features

- Featured Engineering Projects: Detailed technical breakdowns of backend systems, including the Morourak Traffic Services Platform (60+ RESTful APIs, Clean Architecture, CQRS via MediatR, Redis caching, PayMob integration) and the SnapShop E-Commerce API.
- Theme Toggle: Built-in light and dark modes with local storage persistence and system preference synchronization.
- Interactive Media Viewer: Lightweight modal gallery supporting screenshot examination, keyboard controls, and touch swipe navigation.
- Print and PDF Export: Integrated print stylesheet formatted for exporting a clean, resume-style summary directly from the browser.
- SEO and Metadata: Open Graph, Twitter card, and semantic metadata integration for link previews.

## Tech Stack

- HTML5 (Semantic and accessible markup)
- CSS3 (Custom properties, CSS Grid, Flexbox, responsive typography)
- Vanilla JavaScript (ES6+, DOM API, IntersectionObserver)
- Web Fonts: Fraunces, Instrument Sans, JetBrains Mono

## Local Development

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/shahdsolliman/portfolio-.git
   ```
2. Navigate into the directory:
   ```bash
   cd portfolio-
   ```
3. Open `index.html` in any web browser, or launch a local server:
   ```bash
   npx serve .
   ```
