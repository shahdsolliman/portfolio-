# 🚀 Shahd Soliman — Software Developer Portfolio

A modern, high-performance, responsive portfolio engineered for a **Software Developer & Backend .NET Specialist**.

---

## 🌟 Key Features & Improvements
- **Universal Deployment Entry (`index.html`)**: Fully self-contained single-page application ready to deploy anywhere with zero build steps.
- **Developer Theme Switcher**: Interactive Dark Mode / Light Mode toggle with `localStorage` memory and system preference detection.
- **SEO & Social Graph**: Comprehensive Open Graph and Twitter metadata tags for preview cards on LinkedIn, Twitter, and WhatsApp.
- **Embedded Modern SVG Favicon**: Retina-ready `<SS />` code bracket favicon directly inlined.
- **Interactive Tech Stack & Category Filters**: Filter projects smoothly across **Backend & APIs**, **Full-Stack**, and **Client Projects** with live count badges.
- **Flagship Project Showcase**: Highlights **Morourak (Grade A+ Graduation Project)** with Swagger API documentation links, live deployment links, and a full screenshot lightbox.
- **Interactive Lightbox**: Full-screen modal with zoom, keyboard navigation (`←`, `→`, `Esc`), touch swipe for mobile, and thumbnail strip.
- **Quick Action Utilities**: One-click "Copy Email" with animated toast notification and "Print CV" stylesheet support (`Ctrl + P`).

## ⚡ Deployment Options (جاهز للرفع في دقيقة واحدة)

### الخيار 1: الرفع السريع بدون Git عبر Netlify Drop (أسهل وأسرع طريقة في 10 ثوانٍ)
1. افتحي موقع [Netlify Drop](https://app.netlify.com/drop).
2. اسحبي فولدر `PORTFOLIO` بالكامل (Drag and Drop) إلى الصفحة.
3. مبروك! موقعك أصبح متاحاً أونلاين فوراً مع رابط مجاني ورائع مثل `shahd-soliman.netlify.app`.

---

### الخيار 2: الرفع عبر GitHub Pages (الأفضل للمطورين)
1. افتحي [GitHub](https://github.com/new) وأنشئي مستودع جديد باسم `portfolio` أو `shahdsolliman.github.io`.
2. في التيرمينال داخل هذا الفولدر نفذي الأوامر التالية:
```bash
git init
git add .
git commit -m "Initial commit: Production-ready developer portfolio"
git branch -M main
git remote add origin https://github.com/shahdsolliman/portfolio.git
git push -u origin main
```
3. في صفحة المستودع على GitHub:
   - ادخلي إلى **Settings** > **Pages**.
   - تحت **Branch** اختاري `main` واضغطي **Save**.
   - خلال دقيقة سيعمل موقعك مباشرة على `https://shahdsolliman.github.io/portfolio`.

---

### الخيار 3: الرفع عبر Vercel
1. افتحي [Vercel](https://vercel.com).
2. اضغطي **Add New Project** واختاري مستودع الـ GitHub.
3. اضغطي **Deploy** مباشرة (لا يحتاج أي Build Command أو إعدادات إضافية).
